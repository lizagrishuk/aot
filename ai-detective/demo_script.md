# Демонстрация лабораторной № 6 (до 7 минут)

1. **Досье и задача.** Показать 10 документов, 40 claims, 12 вопросов и файл `ground_truth.md`. Объяснить различие документа, claim и evidence.
2. **Одна модель, три режима.** Продемонстрировать A (всё досье), B (BM25 top-15) и C (те же 15, p-adic ветви). Показать в `retrieval_metrics.json` совпадение ID для B/C.
3. **p-adic кодирование.** Показать в `src/padic.py` путь источника/статуса/времени, расстояние по общему префиксу, автоматические тесты ультраметрики. Объяснить почему источник выше времени.
4. **Результаты.** Открыть только **актуальный** `report.pdf`, `results/llm_metrics.json`, примеры ошибок по вопросам. Отдельно показать `safe_fallback`, если он возник.
5. **Стресс.** Показать `results/stress_runs.jsonl` и `stress_metrics.json`: перестановка документов, удаление необходимого факта, добавление противоречия. Подчеркнуть, что B/C при перестановке исходных документов — контроль неизменности контекста.
6. **Интерфейс.** Открыть `streamlit run app.py`: выбрать вопрос, режим, вмешательство, посмотреть источники и таблицу сравнения. Ответить на вопросы об ограничениях: 12 вопросов, одна LLM, возможная вариативность даже при `temperature=0`.

Не озвучивать числа из старых прогонов; использовать только цифры сгенерированного отчёта.
